# afk-releases

The public release channel for merchantlabs/afk-plugin (private).

Install:

```
curl -fsSL https://merchantlabs.github.io/afk-releases/install.sh | sh
```

`install.sh` and `latest.json` (read by `afk update`'s release channel)
live on the `gh-pages` branch here, served by GitHub Pages.

See [Releases](https://github.com/merchantlabs/afk-releases/releases) for every version and its assets.
