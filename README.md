# afk-releases

Release artifacts for [merchantlabs/afk-plugin](https://github.com/merchantlabs/afk-plugin) (private). The manual, covering install, setup, daily use, updating and removal, is that repo's [README](https://github.com/merchantlabs/afk-plugin#readme).

Install: `curl -fsSL https://merchantlabs.github.io/afk-releases/install.sh | sh`
